# 통통한 데이터 분석 — 온라인 부록과 실습 코드

이 저장소는 도서 **『통통한 데이터 분석』**의 온라인 부록, 실습 코드와 예제 데이터를 제공합니다.

온라인 부록의 설명을 읽은 뒤 파이썬 노트북이나 R Markdown 파일을 직접 실행할 수 있습니다.

## 폴더 구성

코드가 데이터 파일을 올바르게 찾을 수 있도록 다음 구조를 유지해 주세요. 모든 코드와 문서는 저장소의 최상위 폴더에 두고, 데이터 파일만 `데이터` 폴더에 둡니다.

```text
.
├── README.md
├── 온라인부록_파이썬.ipynb
├── 온라인부록_R.Rmd
└── 데이터/
    ├── movie_data.csv
    ├── seoul_cultural_events.csv
    ├── seoul_apt_transactions.csv
    ├── reliever_data.csv
    ├── hn19.csv
    ├── boston_marathon_2023.csv
    ├── seoul_apt_dong_model.csv
    ├── seoul_subway_hourly_2024.csv
    ├── k_corporation_reward_survey.csv
    └── mtcars.csv
```

## 실행 방법

저장소 전체를 내려받은 뒤, **저장소의 최상위 폴더를 작업 폴더로 지정하여** 코드를 실행해 주세요. 노트북과 R 코드는 모두 `데이터/파일명.csv` 형식의 상대 경로를 사용합니다.

### 파이썬

JupyterLab 또는 Jupyter Notebook에서 `온라인부록_파이썬.ipynb`를 열고 셀을 순서대로 실행합니다.

```bash
jupyter lab 온라인부록_파이썬.ipynb
```

일부 심화 실습에는 기본 데이터 분석 패키지 외에 추가 패키지가 필요할 수 있습니다. 패키지가 없다는 메시지가 나오면 해당 패키지를 설치한 뒤 셀을 다시 실행해 주세요.

### R

RStudio에서 `온라인부록_R.Rmd`를 열어 실행하거나 다음 명령으로 문서를 렌더링할 수 있습니다.

```r
rmarkdown::render("온라인부록_R.Rmd")
```
